# ElAmir-Mansour/homebrew-tap

Homebrew formulae for my tools.

## Usage

```sh
brew install ElAmir-Mansour/tap/coursekit
```

Or tap it first, then install by name:

```sh
brew tap ElAmir-Mansour/tap
brew install coursekit
```

## Formulae

| | |
|---|---|
| [`coursekit`](https://github.com/ElAmir-Mansour/coursekit) | Inspect, check and tidy folders of course recordings |

Formulae in this repository are generated automatically by
[GoReleaser](https://goreleaser.com) when a release is tagged in the source
repository. Editing them here by hand will be overwritten by the next release.
